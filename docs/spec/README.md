# Original specs

The kickoff specs Thinketh was built from. Code comments refer to them by file name (for example `packages/contracts/src/domain.ts` says it "mirrors 05-data-contracts.md").

| File | What it is |
|---|---|
| `02-architecture-contract.md` | System architecture and adapter boundaries |
| `05-data-contracts.md` | Domain types; `packages/contracts/src/domain.ts` mirrors it |
| `06-demo-runbook.md` | The golden demo path |
| `07-sponsor-checklist.md` | Sponsor integration checklist |
| `09-cut-list.md` | What to cut under time pressure |
| `10-research-notes.md` | Background research |
| `SHARED-INTEGRATION-RULES.md` | How shared contracts change |

The live state of the code has moved on in places. For current API envelopes, `packages/contracts/src/api.ts` is canonical (see `docs/INTEGRATION-NOTES.md`). The per-person kickoff packs these came from are in git history (removed in the repo cleanup).
