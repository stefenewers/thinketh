## Never build during this hackathon unless everything is finished

- marketplace
- agent trading/collection economy
- full LMS
- social network
- AR/VR
- hardware
- commerce
- blockchain
- generic image generation
- admin dashboard

## Emergency mode

If the event clock is dangerous:

1. freeze UI
2. freeze contracts
3. seed all development content
4. keep deterministic knowledge update real
5. keep at least one sponsor integration real
6. preserve temporal history if possible
7. record a stable demo video
