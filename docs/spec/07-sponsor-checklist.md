# Sponsor Challenge Checklist

## Primary track — Oracle of the Deep

Must visibly demonstrate:
- ML/AI reasoning
- meaningful data processing
- visualization
- something the system can infer that a normal feed cannot

Strongest evidence:
- knowledge delta
- uncertainty
- adaptive question selection
- temporal Mind view

## Backboard

Use:
- persistent assistant memory across threads
- learning preferences
- recurring misconceptions
- prior context

Evidence to capture:
- code path / adapter
- two sessions showing recalled context
- screenshot/log for Devpost

Do not claim Backboard owns numeric mastery.

## Tiger Data

Use:
- knowledge observations
- knowledge-state transitions
- time-based history

Evidence:
- hypertable schema
- real inserted transitions
- concept history query
- optional continuous aggregate

Demo phrase:
> Version control for human understanding.

## MongoDB Atlas

Use:
- development/source/concept corpus
- semantic retrieval
- vector search if credentials/index are ready

Evidence:
- Atlas collection
- search/vector index
- query returning related developments or concepts

## ElevenLabs

Use:
- Catch Me Up conversational voice
- interruption/follow-up if stable

Important:
- React Native SDK uses LiveKit/WebRTC
- Expo development build required
- Expo Go is not sufficient for this integration

Evidence:
- live voice session
- fallback transcript

## Notability

During hackathon:
- use Notability Pro for real architecture/design notes
- capture at least two screenshots
- record what it contributed to the process
- add correct Devpost tag

## .tech

If available:
- deploy public landing/demo endpoint on Thinketh .tech domain
- do not spend meaningful engineering time on this

## CREATE-X

Select interest in Startup Launch if submission allows.

## Explicitly not targeting

- SpaceXAI
- Cursor
- Grok
- Visa
- Impiricus
- NSA
- Solana

Do not reintroduce these without a deliberate team decision.
