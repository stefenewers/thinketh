# Thinketh Next-Step Pack v5

HackGT final sprint pack for Claude Code.

## Context

Thinketh is already functionally strong. The remaining opportunity is not more breadth. It is to remove the last "scripted demo" feeling and make the product feel like a premium, quietly futuristic AI-native consumer product.

Current direction:

- Preserve the existing Figma-derived visual system.
- Preserve the golden path.
- Preserve deterministic knowledge-state math.
- Preserve current sponsor integrations.
- Add one high-leverage real-world capability: **real URL -> personalized knowledge delta**.
- Add a **Learning Queue / Save to Learn** surface.
- Make learning visibly change the user's Mind.
- Remove unnecessary raw PKS numbers from normal consumer UI.
- Add lightweight Ask learning modes.
- Ground Explore more in real resources and current state.
- Conduct a high-end visual polish pass.

## Visual benchmark

Think in the territory of premium AI-native products and labs:

- Anthropic
- OpenAI
- Obvious
- Muse
- Jev
- similarly restrained AI-native products

Do not copy them.

Shared qualities to emulate:

- clean
- expensive
- editorial
- quiet
- intelligent
- spacious
- visually disciplined
- subtly futuristic
- little chrome
- strong typography
- intentional motion
- almost no decorative AI clichés

The interface should look simpler than the machinery underneath.
