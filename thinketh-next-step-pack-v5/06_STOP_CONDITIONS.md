# Stop Conditions

This file exists to prevent scope creep.

## Stop adding features when

Any of the following is true:

- the golden path breaks
- native iPhone build becomes unstable
- ElevenLabs regresses
- state reset becomes unreliable
- API tunnel/demo path becomes fragile
- tests fail for more than a short debugging cycle
- new work requires a large new dependency
- new work requires a major migration
- resource ingestion works reliably for one known-good real source
- Teach Me the Delta works
- Knowledge Update visual works
- source provenance is real enough for the demo
- UI polish reaches diminishing returns

## Do not build

Before HackGT submission:

- continuous web ingestion
- RSS/news aggregation
- generalized research crawler
- social/rooms
- production auth overhaul
- multi-user production architecture
- notifications
- general contradiction engine
- agent marketplace
- Solana
- new sponsor integrations
- new database vendors
- admin console
- complex PDF pipeline
- full browser
- project-management features
- advanced recommendation engine
- arbitrary graph layout engine

## If extra time appears

Spend it on:

1. demo rehearsal
2. visual cleanup
3. source quality
4. error handling
5. loading/empty states
6. backup recording
7. Devpost
8. sponsor evidence
9. architecture diagram
10. sleep

A polished narrow product beats a broad unstable one.
