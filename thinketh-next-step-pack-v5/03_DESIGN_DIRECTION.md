# Thinketh Design Direction

## North star

Thinketh should feel like high-end software as an editorial object.

Clean.
Expensive.
Quiet.
Intelligent.
Subtly futuristic.

The product should communicate intelligence through behavior rather than decoration.

## Reference territory

Use the recent direction of premium AI-native products as a quality bar:

- Anthropic
- OpenAI
- Obvious
- Muse
- Jev
- similarly restrained products

Do not imitate brand assets or layouts.

Study the shared principles:

- restraint
- excellent typography
- little visible chrome
- deliberate whitespace
- calm surfaces
- minimal palette
- few primary actions
- smooth micro-interactions
- strong compositional hierarchy

## Existing Thinketh visual DNA

Keep:

- warm off-white background
- neutral inks
- restrained coral
- Playfair for editorial moments
- Inter for utility/body
- quiet borders
- strong whitespace
- progressive disclosure

Do not turn Thinketh into another dark AI dashboard.

## Coral rule

Coral is semantic.

It means:

- new
- changed
- strengthened
- newly connected
- actively updating

It does not mean:

- decoration
- selected nav item everywhere
- random emphasis
- brand filler

If everything is coral, nothing changed.

## Cards

Use fewer cards.

Before adding a card, ask:

"Could typography and spacing establish the hierarchy instead?"

Preferred order:

1. page composition
2. spacing
3. type
4. tonal surface
5. hairline
6. card
7. shadow

Avoid nested cards.

## Typography

Playfair:
- conceptual statements
- major knowledge changes
- reflective/editorial moments

Inter:
- body
- controls
- metadata
- technical text
- labels

Typography should often replace containers as the hierarchy mechanism.

## Motion

The app is mostly still.

Motion appears when intelligence acts.

Use:

- fades
- short translates
- line traces
- node rings
- subtle opacity changes
- restrained haptics

Avoid:

- bounce
- constant looping
- particles
- sparkles
- giant parallax
- decorative animation

## Signature behavior

Knowledge Trace:

`information -> comparison -> delta -> model update -> calm`

The user should learn what coral motion means without needing a legend:

"My understanding just changed."

## UI smell tests

Bad signs:

- every section is a rounded rectangle
- every screen is heading + paragraph + list of rows
- every feature has an icon
- every action has equal weight
- too many dividers
- raw metrics dominate
- loading is generic
- "AI" is communicated with sparkles/gradients
- the Mind graph moves constantly
- the app looks busier than the concept

Good signs:

- one dominant idea per screen
- clear next action
- substantial negative space
- few saturated elements
- strong typography
- sources look like evidence
- transitions explain causality
- complexity disappears underneath the surface
